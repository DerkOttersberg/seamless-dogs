GitHub Actions jobs cannot start because GitHub reports an account billing lock.
[Verified run](https://github.com/DerkOttersberg/seamless-dogs/actions/runs/37480904230).
Local passes are separate from hosted CI.

Runtime dispatchers were stopped when the C drive fell below 2 GB free.
Only the owned disposable QA process trees were stopped. Passed results and
incomplete attempts are retained; the user game and worlds were not controlled.
Observer screenshot helpers now compile on all eleven cells, but their new
capture assertions have not yet run. Final visual acceptance remains pending.
The reviewed 26.3 captures cover petting, stretches, biscuits and chest cleaning;
the full observer/UI/port review is still required. See [remaining work](NEXT-STEPS.md).

The report `acceptance-0.2.0.json` records source commits, JAR hashes and native
scenario names. Detailed logs, failed attempts and private-display captures
are retained in the workspace under
`qa-artifacts/seamless-dogs/standalone-0.2.0`.

Tests use private Xvfb displays and software rendering. They verify entity-bound
sound events through a silent audio device; audible quality and every hardware
driver are outside this coverage. Only recorded optional renderer/protection
builds are claimed. Upstream beta dependencies retain their beta status.

No release install bundle is accepted until the complete matrix passes. No
CurseForge submission or publication was performed.
