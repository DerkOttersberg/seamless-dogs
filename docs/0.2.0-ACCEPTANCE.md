# Standalone 0.2.0 acceptance

This release effort covers eleven cells on four branches: 1.20.1 Fabric/Forge;
1.21.1, 26.2 and 26.3 Fabric/Forge/NeoForge. The owner explicitly removed the
SeamlessLib requirement on 5 October 2026. Builds, CI and loader metadata are
standalone; Fabric still requires Fabric API.

Acceptance is in progress. Earlier preview and 0.1.0 records used different JARs
and do not establish readiness of these standalone builds. Fresh results are
recorded under qa-artifacts/seamless-dogs/standalone-0.2.0, including final hashes,
failed attempts, private-display client captures and multiplayer/lifecycle logs.
No CurseForge submission or publication is part of this development step.
