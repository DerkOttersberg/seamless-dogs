The new legacy fix restores this mod's additive player pose before the next
animation frame, preventing head/body/arm displacement from accumulating during
third-person cat petting. Native capture checks now reject unbounded player
poses. The 1.21.1 build and all three loader native/common checks passed, and its
QA client/lifecycle drivers compiled. The 1.20.1 build was interrupted before
completion; its existing output is not a validated release artifact.

Common tests passed: 21 per modern branch and 22 per legacy branch. Completed
native gates pass eight gameplay scenarios per loader. Earlier 1.20.1 repetitions
and the rejected legacy visual capture are retained as historical evidence; they
do not validate the new player pose fix.

two real clients, late tracking, saved-world restart, lifecycle cleanup, both
player models and hands, adult/baby variants, animation/eye/resource-reload
captures, settings UI review, combined renderer/protection profiles and the
available Seamless suite. All 124 audited logs contain zero unclassified
